# 🤖 بات Sir Mr Yellow: یوتیوب به تلگرام

این پروژه ویدیوهای عمومی تازه‌ی کانال YouTube با شناسه‌ی `@Sir_Mr_yellow138` را پیدا می‌کند و با کپشن فارسی و دو دکمه‌ی زیر پیام در کانال تلگرام می‌گذارد: «🍿 پخشش کن!» و «📺 کانال یوتیوب Sir Mr Yellow».

## راه‌اندازی انتشار ویدیو

1. مخزن را به GitHub خودت منتقل کن و در **Settings → Secrets and variables → Actions** این Secretها را بساز: `YOUTUBE_API_KEY` (کلید فعال YouTube Data API v3)، `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` (مثلاً `@Sirmryellow138`).
2. بات را به کانال تلگرام اضافه کن و دسترسی ارسال پیام/عکس بده.
3. در **Settings → Actions → General → Workflow permissions** گزینه‌ی **Read and write permissions** را فعال کن تا workflow بتواند `state.json` را ذخیره کند.
4. از **Actions → YouTube to Telegram → Run workflow** یک بار دستی اجرا کن. اجرای زمان‌بندی‌شده هر ۱۰ دقیقه است، اما GitHub گاهی آن را با تأخیر اجرا می‌کند.
5. در اجرای اول، حداکثر ۳ ویدیوی تازه‌ی اخیر ارسال می‌شود؛ موارد قدیمی‌تر یا اضافه به‌عنوان دیده‌شده ثبت می‌شوند تا کانال با آرشیو پر نشود. مقدار `INITIAL_POST_LIMIT` را در workflow عوض کن. وضعیت پس از هر ارسال ذخیره می‌شود تا اجرای بعدی موارد موفق را تکرار نکند.

## پیام معرفی کانال

از **Actions → Publish Telegram Intro → Run workflow** اجرا کن. اجرای دوباره به‌صورت پیش‌فرض معرفی را تکرار نمی‌کند؛ برای ارسال مجدد گزینه‌ی `force` را روشن کن.

## منوی خصوصی بات و webhook

برای اینکه `/start` و `/about` و دکمه‌های منو جواب بدهند، سرویس `webhook.py` باید همیشه در دسترس باشد. برای Render از `render.yaml` استفاده کن، متغیرهای `TELEGRAM_BOT_TOKEN` و `TELEGRAM_WEBHOOK_SECRET` را تنظیم کن و بعد از استقرار، webhook را روی آدرس سرویس ثبت کن. اجرای `set_webhook.py` به این متغیرها نیاز دارد: `TELEGRAM_BOT_TOKEN`، `TELEGRAM_WEBHOOK_SECRET` و `TELEGRAM_WEBHOOK_URL`؛ آدرس پایه را بده، مسیر `/telegram` خودش اضافه می‌شود. برنامه با Gunicorn اجرا می‌شود، نه سرور توسعه‌ی Flask.

> پلن رایگان Render ممکن است بخوابد و پاسخ `/start` را با تأخیر بدهد. برای پاسخ فوری و پایدار باید سرویس همیشه‌روشن انتخاب شود.

## محدودیت‌های واقعی YouTube

- YouTube Data API عمومی، Community postهای کانال را ارائه نمی‌کند؛ بنابراین این نسخه ویدیوها و Shorts را پوشش می‌دهد، نه پست‌های Community.
- API پرچم قطعی Shorts ندارد. بات `#shorts` یا مدت حداکثر ۳ دقیقه را ملاک تقریبی می‌گیرد؛ ویدیوی کوتاه افقی ممکن است اشتباهاً Short تشخیص داده شود.
- پخش زنده‌ی در حال اجرا و پریمیرهای آینده منتشر نمی‌شوند.
- هیچ باتی نمی‌تواند ارسال تکراری را صددرصد ناممکن کند اگر تلگرام پیام را بپذیرد ولی پاسخ شبکه در مسیر برگشت گم شود. پروژه هر ارسال تأییدشده را فوراً ذخیره می‌کند و خطاهای عادی را امن مدیریت می‌کند.

## تست محلی

با Python 3.12:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

توکن‌ها را در Secrets نگه دار و داخل کد یا ریپازیتوری عمومی قرار نده. اگر توکن قبلاً جایی منتشر شده، از BotFather باطلش کن.
