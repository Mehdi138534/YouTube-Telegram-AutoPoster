# بات انتشار خودکار یوتیوب در تلگرام

این پروژه آپلودهای عمومی کانال `@Sir_Mr_yellow138` را بررسی می‌کند و ویدیوهای جدید را در کانال تلگرام `@Sirmryellow138` منتشر می‌کند. اجرا با GitHub Actions است و به روشن ماندن کامپیوتر شما نیاز ندارد.

## قابلیت‌ها
- بررسی خودکار هر ۱۰ دقیقه (زمان‌بندی GitHub ممکن است کمی تأخیر داشته باشد).
- ارسال تصویر بندانگشتی، عنوان، بخشی از توضیحات و لینک ویدیو.
- پوشش ویدیوهای معمولی و Shorts؛ API نوع Shorts را به‌صورت قطعی مشخص نمی‌کند، بنابراین برچسب Shorts در این نسخه تخمینی است.
- ذخیره شناسه ویدیوهای پردازش‌شده در `state.json` و commit کردن آن به مخزن برای جلوگیری از تکرار.
- در اجرای اول، به‌طور پیش‌فرض فقط ۳ ویدیوی جدیدتر ارسال می‌شود و بقیه موارد موجود به‌عنوان دیده‌شده علامت می‌خورند.

## ۱. ساخت بات تلگرام
1. در تلگرام به `@BotFather` بروید.
2. دستور `/newbot` را بفرستید و مراحل ساخت را انجام دهید.
3. توکن دریافتی را محرمانه نگه دارید.
4. بات را به کانال `@Sirmryellow138` اضافه کنید و دسترسی ادمین با اجازه ارسال پیام و عکس بدهید.

برای `TELEGRAM_CHAT_ID` می‌توانید از `@Sirmryellow138` استفاده کنید، به شرطی که بات ادمین کانال باشد.

## ۲. ساخت کلید YouTube API
1. به https://console.cloud.google.com/ بروید و یک پروژه بسازید یا انتخاب کنید.
2. از بخش APIs & Services > Library، **YouTube Data API v3** را فعال کنید.
3. از APIs & Services > Credentials یک **API key** بسازید.
4. کلید را در صورت امکان محدود کنید و آن را عمومی نکنید.

## ۳. ساخت مخزن GitHub
1. در https://github.com/new یک مخزن جدید بسازید.
2. فایل‌های این ZIP را در مخزن بارگذاری کنید، از جمله پوشه `.github/workflows`.
3. در Settings > Secrets and variables > Actions > New repository secret این سه Secret را اضافه کنید:

| نام Secret | مقدار |
|---|---|
| `YOUTUBE_API_KEY` | کلید YouTube Data API |
| `TELEGRAM_BOT_TOKEN` | توکن BotFather |
| `TELEGRAM_CHAT_ID` | `@Sirmryellow138` |

مقادیر را در کد یا فایل عمومی قرار ندهید.

## ۴. فعال‌کردن Workflow
1. به تب **Actions** مخزن بروید.
2. اگر لازم بود گزینه **I understand my workflows, go ahead and enable them** را بزنید.
3. workflow با نام **YouTube to Telegram** را باز کنید.
4. روی **Run workflow** بزنید تا تست دستی اجرا شود.
5. خروجی اجرا را باز کنید. در صورت موفقیت، لاگ `Done. Published ...` را می‌بینید.

## ۵. مهم: اجازه commit شدن state
در مخزن بروید به Settings > Actions > General > Workflow permissions و گزینه **Read and write permissions** را فعال کنید. این اجازه برای ثبت `state.json` لازم است. اگر این اجازه داده نشود، ارسال ممکن است انجام شود اما ثبت وضعیت برای اجرای بعدی شکست می‌خورد.

## تنظیم اجرای اول
در فایل `.github/workflows/youtube-to-telegram.yml` مقدار `INITIAL_POST_LIMIT` روی `3` است:
- `3`: سه آپلود جدیدتر در اولین اجرا ارسال می‌شود.
- `0`: در اولین اجرا هیچ ویدیوی قدیمی ارسال نمی‌شود و فقط آپلودهای بعدی منتشر خواهند شد.

پس از اولین اجرا، شناسه‌ها در `state.json` ذخیره می‌شوند تا اجرای بعدی همان ویدیوها را دوباره ارسال نکند.

## نکات و محدودیت‌ها
- این نسخه فقط آپلودهای ویدیویی عمومی را می‌گیرد؛ Community posts در مرحله بعدی هستند.
- نوع Shorts از روی مدت و عنوان حدس زده می‌شود و تشخیص قطعی نیست.
- برای ویدیوی خصوصی/حذف‌شده یا موردی که API برنگرداند، تضمینی وجود ندارد.
- GitHub Actions ممکن است اجرای زمان‌بندی‌شده را با تأخیر اجرا کند.
- اگر اولین اجرای دستی شکست خورد، متن خطای کامل تب Actions را بررسی کنید؛ کلیدها را در پیام عمومی نفرستید.
